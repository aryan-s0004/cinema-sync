STRENGTHS
──────────────────────────────────────────────────────────────────────────────

1. ATOMIC SEAT LOCKING — Production-grade race condition handling using
   MongoDB updateMany with conditional filters. No distributed lock service
   needed. Verified: 409 returned correctly when two users try same seat.

2. SECURITY DEPTH — OTP hashing, JWT rotation, HMAC webhook verification,
   NoSQL injection sanitization, Helmet headers, Joi validation. This is
   multi-layered, not checkbox security.

3. SERVERLESS ARCHITECTURE — Singleton DB connection, no setInterval,
   module-level sweep deduplication. Correctly handles Vercel's ephemeral
   execution model. Pool size 5 prevents Atlas connection exhaustion.

4. DUAL PAYMENT PROVIDER — Mock + Stripe in one codebase, routed by env var.
   Allows development without payment keys and live deployment with Stripe.

5. CLEAN CODE STRUCTURE — Controllers are thin orchestrators. Business logic
   lives in services. No business logic in routes or models. Consistent
   error handling via ApiError/ApiResponse.

6. COMPREHENSIVE AUTH — Email OTP, Phone OTP, Google OAuth, forgot password,
   refresh token rotation, email verification gate. More complete than most
   internship projects.

──────────────────────────────────────────────────────────────────────────────
WEAK AREAS
──────────────────────────────────────────────────────────────────────────────

1. COLD START LATENCY (~500ms on Vercel free tier)
   First request after idle takes 500–600ms. Acceptable for demo but
   noticeable in production.

2. ATLAS M0 LIMITS
   Shared cluster: 512MB storage, 500 connections max. Under sustained load
   (200+ concurrent users), write operations will queue.

3. IN-MEMORY RATE LIMITER
   Not shared across Vercel instances. Each serverless invocation has its
   own counter. Under true multi-instance load, a single IP could bypass limits.

4. NO FRONTEND TESTS
   Zero React component tests. Regression risk on UI changes.

5. OPENAI NOT CONFIGURED
   Recommendation endpoint falls back to genre-match. AI feature exists in
   code but is inactive in production.
